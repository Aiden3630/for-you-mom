# Как сделать подарок своим

Откройте `src/config/gift.config.ts`, измените значения и выполните `npm run build`. Компоненты менять не нужно. Перед подарком обязательно прочитайте письмо целиком и убедитесь, что оно звучит вашим голосом.

## Имена, дата и поздравление

```ts
motherName: 'мама',
sonName: 'Андрей',
siteTitle: 'Для тебя, мам',
holidayDate: '2026-11-29',
```

Дата — в формате ГГГГ-ММ-ДД. В текстах можно использовать `{mom}` и `{son}`; они заменяются значениями из конфигурации. По умолчанию `sonName` равно «твой сын». Основной заголовок редактируется в `intro.title`, надпись на конверте — в `intro.envelopeLabel`. Заголовок вкладки и название в шапке — `siteTitle`.

`letter.greeting` — обращение, `letter.paragraphs` — массив абзацев, `letter.closing` — заключение. Количество абзацев произвольное. Сохраните обычные кавычки TypeScript, запятые между элементами и не удаляйте фигурные скобки.

## Настоящие фотографии

Положите JPEG/WebP/PNG в `public/photos`. Названия лучше писать латиницей без пробелов. Желательно 1200–1600 пикселей по длинной стороне и до 300 КБ. Снимки не отправляются в какие-либо сервисы оптимизации.

В `photos` уже добавлены ваши пять снимков. Для добавления нового элемента используйте такую структуру:

```ts
photos: [
  {
    src: 'photos/my-photo.webp',
    caption: 'Ваша настоящая подпись',
    date: 'Дата или год, если хотите',
    alt: 'Краткое описание того, что изображено на снимке',
  },
],
```

Это пример структуры, а не сведения о семье. Добавляйте сколько угодно элементов. Пустые `src` скрываются. Повреждённый или отсутствующий файл показывает аккуратное сообщение; другие главы продолжают работать. Если фотографий нет, остаются художественные пустые рамки. Увеличенные снимки переключаются кнопками, Escape закрывает просмотр, фокус возвращается к исходному снимку. Свайп по альбому меняет страницу. Даты не обязательны.

## Благодарности и пожелания

`thanks` — массив объектов `{ title, text }`; по умолчанию десять писем. `wishes` устроен так же: каждый элемент создаёт цветок с пожеланием. Названия и тексты можно менять без ограничений. Для красивой композиции на смартфоне рекомендуются 5–9 пожеланий; при большем количестве цветы переносятся на дополнительные ряды. Переход дальше всегда доступен: открывать всё необязательно.

## Музыка

В качестве сопровождения подключён предоставленный вами файл **Amberlight — Scott Buckley** (`public/music/amberlight.mp3`). Пользователь запускает его через «Музыка → Включить музыку»; трек не прерывается при смене главы. Авторство и лицензия CC BY 4.0 находятся в `music.credit`, панели музыки и `public/music/LICENSE.txt`. Чтобы заменить композицию, положите новый MP3/WAV в `public/music` и обновите `music`, включая сведения об авторе:

```ts
music: {
  src: 'music/your-track.mp3',
  title: 'Название вашей композиции',
  defaultVolume: 0.25,
},
```

`defaultVolume` — число от 0 до 1. Чтобы убрать музыку, укажите `src: ''`. Сайт продолжит работать; при ошибке загрузки покажет возможность смотреть в тишине. Изменение стартовой громкости не отменяет уже сохранённые настройки получателя. Очистка настроек — через очистку данных сайта браузером.

## Цвета, финал и секрет

В `palette` меняются шесть базовых цветов. Компоненты используют эти CSS-переменные, основные оттенки SVG-лепестков и листьев тоже выводятся из палитры. Второстепенные оттенки бумаги и ветвей остаются тёплыми нейтральными. Подбирайте контраст текста на кремовом фоне. `final` содержит основной заголовок, пожелание, «Я люблю тебя» и подпись. Эти же данные используются при экспорте открытки. `secret` — сообщение, доступное через маленькое сердце внизу.

## Отключение глав

Укажите `enabled: false` у любой главы в массиве `chapters`. Навигация и кнопки перехода автоматически пропустят её. `label` меняет короткую подпись главы в оглавлении. Порядок элементов задаёт порядок путешествия. Если хотите открыть сразу письмо, отключите `intro`. Изменённая сборка не требует серверных маршрутов.

## Перед вручением

Проверьте на телефоне имена, письмо, все фото, звук, громкость, PNG и окончательную ссылку. Не публикуйте семейные материалы без согласия близких. После `npm run build` фото попадут в `dist`, даже если они исключены из Git. Для личного подарка можно оставить сайт локальным и показать его на своём устройстве.
