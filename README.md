# Для тебя, мам

GitHub Pages: [открыть подарок](https://aiden3630.github.io/for-you-mom/). [Исходники на GitHub](https://github.com/Aiden3630/for-you-mom).

Личный интерактивный подарок ко Дню матери: семь глав, письмо, альбом настоящих фотографий, десять благодарностей, цветочный сад и открытки PNG. Полностью статический React + TypeScript + Vite, Tailwind CSS, Motion и Lucide. Никаких учётных записей, аналитики, CDN и запросов к сторонним сервисам во время просмотра.

## Быстрый запуск

Нужен Node.js 22.12+ либо 24 LTS с npm.

```sh
npm ci
npm run dev
```

Откройте напечатанный Vite адрес. Начало истории – `/#intro`; главы доступны через оглавление и нижнюю навигацию. Звук включается отдельно в меню «Музыка». Громкость и согласие на звук сохраняются в localStorage; после перезагрузки музыка ждёт действия пользователя.

## Персонализация

Редактируйте **src/config/gift.config.ts**. Подробности и пример с фотографиями: [PERSONALIZATION.md](PERSONALIZATION.md). В альбом добавлены пять предоставленных семейных фотографий. На телефоне показан один крупный снимок, на большом экране – два; работают свайпы, увеличение и стрелки клавиатуры. Снимки отображаются целиком, даты событий не выдуманы. Все главы можно отключить через `enabled`; если отключены абсолютно все, останется вступление.

## Готовая сборка и просмотр без интернета

```sh
npm run build
npm run serve:offline
```

Готовый сайт находится в `dist`, локальный адрес – `http://127.0.0.1:4173`. Интернет для просмотра не требуется: шрифты, графика и музыка включены в сборку. Для переноса достаточно папки `dist` и `scripts/serve.mjs` (Node.js должен быть установлен). Скрипт не использует npm-библиотеки. Например, `node scripts/serve.mjs dist`. Через двойной щелчок по `index.html` модули браузера не запускаются – нужен этот простой сервер.

Отдельный готовый комплект – `delivery/gift-offline.zip`. Распакуйте его, откройте `START-HERE.txt` внутри `offline-gift`. В Windows можно запустить `Открыть подарок.cmd`. Node.js должен быть установлен заранее. Этот ZIP соответствует текущей сборке; после персонализации пересоберите `dist` и обновите содержимое `delivery/offline-gift/dist`, затем создайте ZIP заново.

## Проверки

```sh
npm run typecheck
npm run lint
npm run build
npm run test:e2e
npm run check:production
```

Playwright настроен на Chromium, Firefox, WebKit и установленный Microsoft Edge. Для первого запуска браузеров: `npx playwright install chromium firefox webkit`. Если Edge на компьютере отсутствует, запустите `npx playwright test --project=chromium --project=firefox --project=webkit`. Скриншоты и отчёт фактического прогона находятся в `output/playwright` и [TEST-REPORT.md](TEST-REPORT.md). Установка браузеров требует интернета. Установка зависимостей фиксируется `package-lock.json`. Проверка production использует установленный Edge и порты 4173/4174; она также создаёт печатный PDF.

## GitHub Pages

1. До публикации проверьте, какие фотографии попадут в репозиторий и `dist`: GitHub Pages обычно доступен публично. `.gitignore` не скрывает уже отслеживаемые снимки и содержимое сборки.
2. Настройте GitHub Pages с источником GitHub Actions. Готовый workflow: `.github/workflows/deploy.yml`, запускается вручную через Actions → Deploy gift → Run workflow.
3. В Settings → Pages выберите GitHub Actions. Workflow автоматически использует `/<имя-репозитория>/`, для репозитория `<пользователь>.github.io` – `/`.
4. Для ручной сборки под подкаталог PowerShell:

```powershell
$env:VITE_BASE_PATH='/mom_day/'
npm run build
Remove-Item Env:VITE_BASE_PATH
```

Для Bash: `VITE_BASE_PATH=/mom_day/ npm run build`. Загрузите содержимое `dist` в источник Pages. Навигация использует hash, поэтому серверные перенаправления не нужны. По умолчанию base равен `./` – переносимая сборка также поддерживает подкаталог.

## Cloudflare Pages

В Pages создайте проект, подключите репозиторий или загрузите `dist` через Direct Upload. Для Git-интеграции: build command `npm run build`, output directory `dist`, Node.js 24. Не задавайте `VITE_BASE_PATH` при публикации в корне домена. Платные API и Workers не нужны. Для ограниченного доступа используйте средства контроля доступа хостинга; секретная ссылка, robots.txt и клиентский пароль не защищают семейные материалы.

## Как вручить подарок

После выбора **окончательного адреса**:

```sh
npm run qr -- https://your-final-address.example/
```

Скрипт создаёт `delivery/qr.svg`, `delivery/qr.png`, `delivery/final-url.txt`. Он не отправляет адрес стороннему QR-сервису. Откройте `delivery/card.html`, QR появится автоматически, нажмите «Распечатать открытку». Формат A6, масштаб 100%, без колонтитулов, включите печать фона. До появления адреса открытка содержит честно обозначенное место для QR. Готовый PDF без QR: `delivery/card-a6.pdf` (если создан при проверке). Проверьте итоговый QR камерой реального телефона перед вручением.

## Ресурсы и лицензии

Текущее сопровождение – предоставленный пользователем MP3 **Amberlight – Scott Buckley**, скопированный без изменения звука в `public/music/amberlight.mp3`. Авторство и CC BY 4.0 указаны в панели музыки и `public/music/LICENSE.txt`; [страница автора](https://www.scottbuckley.com.au/library/amberlight/), [лицензия](https://creativecommons.org/licenses/by/4.0/). Музыка пробует запуститься при открытии сайта, при блокировке браузером – после первого действия. Она играет непрерывно между главами, с плавным включением и отключением. Выключение и громкость сохраняются. Старый «Тихий сад» остаётся доступен как необязательная альтернатива по CC0, генератор – `scripts/generate-music.mjs`.

PNG-открытки различаются: первая сохраняет нарисованный букет, финальная – совместную фотографию в рамке с надписью «Я люблю тебя». Изображение для неё задаётся в `final.photo`; при его отсутствии используется сердце.

Фотографии и MP3 читаются из файлов сайта. Оригиналы в папках пользователя не изменялись. По отдельному явному разрешению владельца репозиторий GitHub и сайт GitHub Pages общедоступны, включая семейные фотографии. Копия в Sites сохраняет прежний закрытый доступ только владельцу. Скриншоты и офлайн-архив исключены из Git. `.gitignore` не скрывает уже отслеживаемые файлы.

Цветочная SVG-графика создана для проекта. Шрифты Cormorant Garamond и Manrope поставляются локально пакетами Fontsource под SIL OFL; копии лицензий – `public/fonts/licenses/`. Остальные библиотеки сохраняют собственные открытые лицензии в npm-пакетах.

Подключение библиотек сверено с официальными инструкциями [Tailwind CSS для Vite](https://tailwindcss.com/docs/installation/using-vite) и [Motion для React](https://motion.dev/docs/react-installation). TypeScript выбран в ветке, поддерживаемой typescript-eslint; точные версии зафиксированы в lock-файле.

## Примечания

Публикация не выполняется автоматически. Личные данные живут в статических файлах сайта. Safari на iPhone может открыть PNG вместо немедленного скачивания: сохраните изображение через системное меню. После экспорта также доступна явная ссылка на PNG. Анимации отключаются при системной настройке уменьшения движения. Альбом поддерживает любое число фотографий, разбитых по две на страницу, свайпы и увеличение с клавиатурным закрытием Escape.
